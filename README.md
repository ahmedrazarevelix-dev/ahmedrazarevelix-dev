## 🧑‍💻 About Me

I'm an **AI Engineer and Software Engineer** (Computer Science student) who builds production-ready systems end to end — from architecture and database design to implementation, automated testing, and deployment.

I specialize in the **Model Context Protocol (MCP)**, **Retrieval-Augmented Generation (RAG)**, and **agentic AI workflows with LangGraph**, backed by strong backend engineering in **JavaScript/Node.js (Express)** and **Python (FastAPI, Django)**. I focus on AI products and backend systems that work in production, not just in notebooks.

### 🎯 What I Do

🤖 **MCP, RAG & Agentic AI**

- MCP servers and clients, tool/resource design, and connecting LLMs to external systems and APIs
- RAG systems with LangChain and vector-based retrieval for accurate, context-aware responses
- Multi-step autonomous workflows with LangGraph — tool use and orchestration beyond single-shot prompting

🔧 **Backend & API Development**

- Scalable server-side applications and REST APIs with Node.js/Express, FastAPI, and Django
- Authentication, business logic, and database integration
- Layered architecture with clean separation of concerns

🗄️ **Database Design**

- DBMS, schema design, and data modeling for large-scale and AI-driven applications
- Normalized, scalable schemas with relationships and indexing

🧪 **Testing, Quality & Prompt Engineering**

- Unit, integration, and end-to-end testing, plus automation testing before release
- Prompt engineering and evaluation to reduce hallucinations and improve LLM output consistency

### 💡 What Sets Me Apart

- End-to-end ownership: architecture → database design → implementation → testing → deployment
- Production mindset: AI and backend systems validated with automated tests before release
- Bridges AI and backend engineering — reliable, structured LLM access to tools, data, and services
